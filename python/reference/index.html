    Python API Reference¶

    TokenBridge¶

    The main client class. Import and instantiate once; use tb.fetch() for data and tb.auth_url() for participant onboarding.

    tokenbridge.TokenBridge(url: Optional[str] = None, api_key: Optional[str] = None, env_file: str = '.env', provider: str = 'google-health') ¶

    Client for the TokenBridge token management service.

    Responsible for auth URL generation, token retrieval, and routing data requests to the correct provider. Set tb.provider once at the top of your script; use tb.fetch() for all data fetching.

    Use tb.google / tb.withings as provider-namespaced shortcuts — they pre-bind the provider and forward every call to the underlying provider instance, so tb.google.summary(...) also works.

    See docs/providers.md for supported providers and data type IDs.

    Attributes:

    Name Type Description
    provider

    Default provider ID used by fetch(), auth_url(), get_token(), and token_status() when provider= is not passed explicitly. Change at any time to switch providers mid-script. Default: "google-health".
    google _ProviderProxy

    Provider namespace proxy pre-bound to "google-health".
    withings _ProviderProxy

    Provider namespace proxy pre-bound to "withings".
    Example 
    tb = TokenBridge()
tb.provider = "google-health"

print(tb.auth_url("p001"))
sleep = tb.fetch("p001", "sleep", "2026-05-01", "2026-06-18")
steps = tb.fetch("p001", "steps", "2026-05-01", "2026-06-18")

# One token for multiple fetches
token = tb.get_token("p001")
sleep = tb.fetch("p001", "sleep", start, end, token=token)
hrv   = tb.fetch("p001", "heart-rate-variability", start, end, token=token)

    Initialise the TokenBridge client.

    Reads TOKENBRIDGE_URL and TOKENBRIDGE_API_KEY from environment variables (or the specified .env file). Explicit arguments take precedence over environment variables.

    Parameters:

    Name Type Description Default
    url Optional[str]

    TokenBridge base URL, e.g. "https://abcdef.supabase.co/functions/v1". Reads TOKENBRIDGE_URL from env if not provided.

    		 None
    api_key Optional[str]

    TokenBridge API key. Reads TOKENBRIDGE_API_KEY from env if not provided.

    		 None
    env_file str

    Path to the .env file to load. Default ".env".

    		 '.env'
    provider str

    Default provider ID. Default "google-health".

    		 'google-health'

    Raises:

    Type Description
    RuntimeError

    If TOKENBRIDGE_URL or TOKENBRIDGE_API_KEY cannot be resolved from arguments or environment.
    Example 
    # Reads .env automatically
tb = TokenBridge()

# Explicit credentials (no .env needed)
tb = TokenBridge(
    url="https://abcdef.supabase.co/functions/v1",
    api_key="my-key",
)

    fetch(user_id: str, data_type: str, start_date: str, end_date: str, *, provider: Optional[str] = None, token: Optional[str] = None) -> list[dict] ¶

    Fetch health data for a participant.

    Routes to the appropriate provider and returns a flat list of records. Each record is a dict with dot-notation keys for nested API fields, e.g. startTime.seconds.

    data_type is the kebab-case type ID — e.g. "sleep", "steps", "heart-rate-variability". See docs/providers.md or:

    from tokenbridge.providers.google_health import DATA_TYPES
print(list(DATA_TYPES))

    Parameters:

    Name Type Description Default
    user_id str

    TokenBridge participant ID.

    		 required
    data_type str

    Kebab-case data type ID.

    		 required
    start_date str

    Start of date range, "YYYY-MM-DD".

    		 required
    end_date str

    End of date range, "YYYY-MM-DD".

    		 required
    provider Optional[str]

    Override the session default (tb.provider) for this call only. Does not change tb.provider.

    		 None
    token Optional[str]

    Pre-fetched access token. Pass when fetching multiple types for the same participant to avoid repeated TokenBridge round-trips. Obtain with tb.get_token(user_id).

    		 None

    Returns:

    Type Description
    list[dict]

    List of dicts, one per data point. Returns an empty list if no
    list[dict]

    data exists for the period.
    Example 
    # Basic
sleep = tb.fetch("p001", "sleep", "2026-05-01", "2026-06-18")

# Token reuse
token = tb.get_token("p001")
sleep = tb.fetch("p001", "sleep",  start, end, token=token)
steps = tb.fetch("p001", "steps",  start, end, token=token)
hrv   = tb.fetch("p001", "heart-rate-variability", start, end, token=token)

# One-off provider override
tb.fetch("p001", "sleep", start, end, provider="withings")

    get_token(user_id: str, provider: Optional[str] = None) -> str ¶

    Fetch a valid access token for a participant.

    TokenBridge refreshes automatically if the token is within 5 minutes of expiry.

    You rarely need this directly — tb.fetch() handles it internally. Use it when fetching multiple data types for the same participant to avoid one TokenBridge round-trip per call:

    Parameters:

    Name Type Description Default
    user_id str

    TokenBridge participant ID.

    		 required
    provider Optional[str]

    Provider. Defaults to tb.provider.

    		 None

    Returns:

    Type Description
    str

    OAuth access token string.
    Example 
    token = tb.get_token("p001")
sleep = tb.fetch("p001", "sleep",  start, end, token=token)
steps = tb.fetch("p001", "steps",  start, end, token=token)
hrv   = tb.fetch("p001", "heart-rate-variability", start, end, token=token)

    Provider namespaces¶

    tb.google and tb.withings are lightweight proxy objects. They pre-bind a provider and forward every call to the underlying provider instance. This means all GoogleHealth methods are available as tb.google.<method>.

    tb.google.fetch("p001", "sleep", start, end)           # same as tb.fetch(..., provider="google-health")
tb.google.summary("p001", start, end)                  # GoogleHealth.summary
tb.google.data_completeness(["p001", "p002"], s, e)    # GoogleHealth.data_completeness

    They are read-only properties on TokenBridge — you cannot assign to tb.google.

    GoogleHealth¶

    The underlying Google Health provider. You can use this directly if you prefer not to go through tb.fetch(), for example when building scripts that only use one provider:

    from tokenbridge import TokenBridge, GoogleHealth

tb = TokenBridge()
gh = GoogleHealth(tb)

sleep = gh.fetch("p001", "sleep", start, end)
s     = gh.summary("p001", start, end)

    tokenbridge.GoogleHealth(tb) ¶

    Bases: HealthProvider

    Google Health API v4 provider (Fitbit-backed).

    Usually accessed via tb.google rather than instantiated directly.

    All public methods accept an optional token argument. Pass a pre-fetched token to avoid one TokenBridge round-trip per call when fetching multiple types for the same participant:

    token = tb.get_token("p001")
sleep = gh.fetch("p001", "sleep",  start, end, token=token)
steps = gh.fetch("p001", "steps",  start, end, token=token)
hrv   = gh.fetch("p001", "heart-rate-variability", start, end, token=token)

    fetch(user_id: str, data_type: str, start_date: str, end_date: str, *, token: Optional[str] = None) -> list[dict] ¶

    Fetch any Google Health data type by its ID.

    This is the primary method — all named helpers (fetch_sleep, etc.) delegate here. Automatically routes to the correct endpoint type (list or dailyRollup) based on DATA_TYPES.

    Parameters:

    Name Type Description Default

    TokenBridge participant ID.

    		 required
    data_type str

    Kebab-case type ID, e.g. "sleep", "steps", "heart-rate-variability". Must be a key in DATA_TYPES.

    		 required
    start_date str

    Start of date range, "YYYY-MM-DD".

    		 required
    end_date str

    End of date range, "YYYY-MM-DD".

    		 required
    token Optional[str]

    Pre-fetched access token. Pass when fetching multiple types to avoid repeated TokenBridge round-trips.

    		 None

    Returns:

    Type Description
    list[dict]

    List of flat dicts, one per data point. Nested API fields are
    list[dict]

    flattened with dot notation, e.g. startTime.seconds.
    list[dict]

    Returns an empty list if no data exists for the period.
    Example

# Loop all types with one token
token = tb.get_token("p001")
for dt in DATA_TYPES:
    data = gh.fetch("p001", dt, start, end, token=token)

    DATA_TYPES¶

    A dict mapping every supported Google Health type ID to its endpoint type ("list" or "dailyRollup"). Use it to enumerate all available types:

    from tokenbridge.providers.google_health import DATA_TYPES

for dtype in DATA_TYPES:
    data = tb.fetch("p001", dtype, start, end, token=token)
    print(dtype, len(data))
